# Datheon Task 1 — Personal Developer Portfolio

A responsive personal portfolio website created for Datheon Internship Task 1. The website introduces my background, showcases my technical skills and projects, and provides ways to connect with me.

## Features

- Personal introduction and About Me section
- Technical skills showcase
- Featured projects with interactive project details
- Résumé section
- Contact and social links
- Dark and light theme toggle
- Responsive navigation for mobile devices
- Smooth scrolling and section reveal effects
- Responsive layout for desktop, tablet, and mobile screens

## Projects Showcased

- **TaskPilot AI** — A productivity and task-planning project.
- **LaunchPad** — A portfolio-building project.
- **MindFlow AI** — An AI application prototype.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Run Locally

1. Clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the Live Server extension.
